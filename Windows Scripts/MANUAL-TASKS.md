# Tasks still requiring manual checks

The [PowerShell script](windows-10-11.ps1) handles repetitive inventory and some individual security changes. It cannot determine what is authorized on your specific image. The items below still require reading the README, inspecting the Windows GUI, or verifying real application behavior. Follow these sections of the [full Windows 10/11 guide](../Windows/windows-10-11.md).

## Do before any script changes

- **README and evidence:** Identify authorized users, group names, critical services, required programs, prohibited content and any tasks you must answer before making changes. [Before touching anything](../Windows/windows-10-11.md#0-before-you-touch-anything) · [Forensics questions](../Windows/windows-10-11.md#1-forensics-questions-first).
- **Scoring and recovery:** Record the current score and working administrator account. A script cannot promise points, detect every scored vulnerability or restore a deleted user with its original SID. [Final checks](../Windows/windows-10-11.md#18-final-checks) · [Recovery procedures](../Windows/windows-10-11.md#19-manual-verification-recovery-and-missing-investigation-steps).

## Windows security settings

| What to do manually | Why it is not fully automated | Guide |
|---|---|---|
| Verify the correct password, lockout and domain policy; recover from policy conflicts | The script can apply explicitly entered *local* values, but cannot infer scoring targets or override an applicable domain GPO | [Password Policy](../Windows/windows-10-11.md#31-password-policy) · [Account Lockout Policy](../Windows/windows-10-11.md#32-account-lockout-policy) |
| Check all audit, user-rights and security-options assignments | Rights can be granted to service principals or inherited through GPO; removing the wrong one can disable access | [Audit Policy](../Windows/windows-10-11.md#41-audit-policy-record-security-events) · [User Rights Assignment](../Windows/windows-10-11.md#42-user-rights-assignment) · [Security Options](../Windows/windows-10-11.md#43-security-options) |
| Check Defender exclusions, third-party antivirus, detections and Tamper Protection | The script can remove a *named* exclusion or start a scan, but cannot determine which files and exceptions are legitimate | [Defender](../Windows/windows-10-11.md#5-microsoft-defender-antivirus) |
| Review inbound firewall exceptions and confirm actual connectivity | Enabling profiles does not remove unauthorized rules or prove required remote connections work | [Firewall rules](../Windows/windows-10-11.md#62-check-the-inbound-rules) |
| Verify updates and required application paths | Installing OS updates, browser versions or Notepad++ can require vendor installers, license prompts, reboot planning and preserved defaults; `winget` may not be available | [Windows Update](../Windows/windows-10-11.md#7-windows-update) · [Update programs](../Windows/windows-10-11.md#73-update-the-other-programs) · [Web browsers](../Windows/windows-10-11.md#16-web-browsers) |
| Configure Defender SmartScreen, browser site permissions and screen locking | Application profiles and browser settings often require per-user GUI actions and cannot safely be applied to every account | [SmartScreen](../Windows/windows-10-11.md#155-smartscreen-on) · [Screen locking](../Windows/windows-10-11.md#153-screen-saver-with-password) · [Chrome](../Windows/windows-10-11.md#163-google-chrome--browser-update-and-settings) |
| Inspect UAC, PrintNightmare and SMB compatibility | These changes can disrupt printing, legacy shares, application installation or elevation | [UAC](../Windows/windows-10-11.md#151-user-account-control) · [Print spooler](../Windows/windows-10-11.md#83-printer-drivers-printnightmare-fixes) · [SMB settings](../Windows/windows-10-11.md#43-security-options) |

## Users, files and services

- **User and group decisions:** The script can create a local group, add/remove specific members, change passwords and handle specifically named users. **You still have to compare every name and permission to the README**, preserve the working administrator, and verify sign-in and group membership in `lusrmgr.msc`. [Users and groups](../Windows/windows-10-11.md#2-users-and-groups) · [Create group](../Windows/windows-10-11.md#29-create-a-required-custom-local-group) · [Add group members](../Windows/windows-10-11.md#210-add-the-specified-users-to-the-required-group).
- **Unwanted programs and archives:** The script can attempt a named `winget` uninstall or a single-file deletion. **You must identify the exact application/package/file**, including anything installed outside `winget`, and protect forensic evidence. [Prohibited software](../Windows/windows-10-11.md#12-prohibited-software) · [Portable tools](../Windows/windows-10-11.md#123-portable-tools-that-arent-installed) · [Prohibited files](../Windows/windows-10-11.md#13-prohibited-files).
- **Suspicious executables, backdoors, and persistence:** Audit results and ports are leads, not confirmed malware. Inspect the executable path, signature, parent process, Registry Run keys, Task Scheduler, services, the hosts file and required software before removal. The script intentionally does **not** automatically kill unexplained processes or delete scheduled tasks. [Backdoors and malware](../Windows/windows-10-11.md#14-backdoors-and-malware) · [Startup tasks](../Windows/windows-10-11.md#142-scheduled-tasks) · [Advanced investigations](../Windows/windows-10-11.md#21-advanced-windows-investigations--included-in-this-checklist).
- **Remote access and system services:** Never disable a listener, RDP/SSH/WinRM, IIS, SMB, DNS or printing just because it appears in a checklist. The script can disable selected named services, but cannot know their true dependencies. [Remote access](../Windows/windows-10-11.md#10-remote-access) · [Services](../Windows/windows-10-11.md#8-services) · [Critical services](../Windows/windows-10-11.md#17-critical-services).
- **Shared folders and permissions:** The script can remove a specific confirmed unauthorized custom share, but it cannot reconstruct NTFS/share ACLs, and it must not remove Windows administrative shares. [Shared folders](../Windows/windows-10-11.md#11-shared-folders) · [Share and NTFS permissions](../Windows/windows-10-11.md#197-smb-share-permissions-and-ntfs-permissions).
- **Optional features and legacy protocols:** The script offers SMB1 removal when appropriate, but you must check required file shares, Telnet, SNMP, OpenSSH, NetBIOS and other dependencies. [Windows features](../Windows/windows-10-11.md#9-windows-features) · [Other settings](../Windows/windows-10-11.md#15-other-settings).

## Finish the image

Run audit again and compare it to your first report. Open the Scoring Report, check for penalties, confirm the administrator login, required browsers, required shares, network and critical services. A change that makes the computer look more secure but breaks a README-required function can lose points. Use the [final verification checklist](../Windows/windows-10-11.md#18-final-checks).
