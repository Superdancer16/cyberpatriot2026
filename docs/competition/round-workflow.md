# Round workflow

## Turn the brief into a matrix

Record each required user, service, application and constraint with an owner and verification method. Example: required file share → Windows operator → open the share as the approved standard user. Leave ambiguities marked for coach review.

## Establish a baseline

Record score, time, OS, available admin access and required service status. Work on evidence questions first. Take a snapshot only if permitted and record its purpose.

## Execute in batches

Start with explicit discrepancies that can be reversed. For each batch record original state, intended change and how to verify. Check functionality and scoring before moving to another batch.

## Handle a regression

Pause edits, record the first observed failure and identify the last relevant change. Restore that setting when authorized, then recheck the affected feature and score. Escalate if recovery would risk other completed work.
