# Team operations

## Ownership

Assign one operator per image, one reviewer for risky changes and one person to track time and score. Hand off by naming the image, last change, open risk and next verification.

## Change record

Use the template: time / operator / requirement / observed state / change / verification / rollback. Example: 10:15 / Windows operator / approved file access / excessive share grant / narrowed group grant / approved user can still read / restore prior share ACL.

## Mentor practice plan

Run separate sessions for brief reading, identity review, services and firewall, forensics, networking and a timed mock round. End each session by asking students to show the evidence for a decision and demonstrate how they would reverse it.
