# Forensics and evidence handling

## Preserve evidence

Read every question before remediation. Record the requested answer format and artifact path. Inspect relevant evidence before changing the account, application or service it describes.

## Work through a question

For a file hash, confirm the requested algorithm and exact file. For a log question, correlate timestamp, timezone, account, event type and outcome. For a process or port question, corroborate listener, process owner, executable path and service identity. For package ownership, compare the package inventory with the artifact path.

## Record the answer

Separate observation from inference. Record the source and time in approved private notes, then enter only the answer format requested. Recheck capitalization and timezone before moving on.
