# Image Review Checklist

Use this checklist to guide inspection. A listed item is not automatically a finding or authorization to change it.

## Instructions and constraints

- [ ] Read all image-specific instructions.
- [ ] Identify required users, services, applications, files, and network behavior.
- [ ] Confirm prohibited actions and approved resources with the coach or team lead.
- [ ] Note the round time limit and the scoring mechanism.

## Initial inspection

- [ ] Record the operating system and version.
- [ ] Confirm system time and hostname if relevant to the instructions.
- [ ] Review user and group membership for unexpected or unauthorized entries.
- [ ] Review password and account policies against the instructions.
- [ ] Inspect startup items, scheduled tasks, and running services for unfamiliar entries.
- [ ] Review firewall, remote access, and sharing settings.
- [ ] Check installed software and updates against image requirements.
- [ ] Inspect security logs or system history when the time allows and the team is trained to interpret them.

## Before each change

- [ ] Is the issue supported by evidence or explicitly named in the instructions?
- [ ] Could this affect a required user, service, application, or scoring task?
- [ ] Is the action allowed by current rules and coach guidance?
- [ ] Is there a clear way to verify the result and recover if needed?
- [ ] Has the planned change been communicated and recorded?

## Final review

- [ ] Recheck requirements from the image instructions.
- [ ] Confirm required services and applications still work.
- [ ] Recheck score and task status.
- [ ] Communicate unresolved items and any recovery steps to the team lead.
