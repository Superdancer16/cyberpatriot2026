# Linux and FreeBSD — Prioritized CyberPatriot Manuals

## Begin with Basics, then First Things to Do

All three main Linux guides are now structured by learning stage and practical priority: **Basics / Info → README and Forensics → Common Security Checks → Services/Software → Advanced and Recovery → Final Verification**.

- [Debian — Comprehensive Standalone Handbook](debian.md) — root/sudo, PAM, apt/deb822 sources, nftables/UFW, required services and full advanced references.
- [Linux Mint — Comprehensive Standalone Handbook](linux-mint.md) — Cinnamon/LightDM, Update Manager, Flatpak, sudo/PAM, desktop/service security and advanced references.
- [Ubuntu — Comprehensive Standalone Handbook](ubuntu.md) — **expanded** Ubuntu 22/24 guide covering APT vs Snap, GNOME, UFW, SSH socket activation, Netplan/NetworkManager, systemd, AppArmor and critical services.
- [FreeBSD](freebsd.md) — a separate BSD operating system, **not a Linux distribution**; use FreeBSD-specific commands.

**Do first:** [Read the image README](../General/All/reading-the-readme.md) and preserve [forensics answers](../General/All/forensics-questions.md). Check the exact OS release and required users/daemons before modifying accounts, packages, firewall, login or authentication.

**No executable scripts are included.** All command examples remain in the Markdown guides for manual inspection, verification and controlled recovery.
