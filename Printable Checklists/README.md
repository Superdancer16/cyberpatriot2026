# Printable CyberPatriot Checklists

These are **separate, printable task checklists** based on the existing, comprehensive guides. **None of the original Windows, Debian, Windows Server or Cisco guides were modified.**

The PDFs are black-and-white-friendly, **US Letter (8.5 x 11 in), portrait**. Print at **100% / Actual Size**, then tick one square after each individual inspection, permitted fix or verification. Write **N/A** beside tasks that do not apply to your assigned image or Cisco activity.

## Print and check tasks on paper

1. Open the appropriate PDF above, select **Download**, and print on **US Letter portrait at Actual Size**.
2. Write the round/date, computer image or activity, team, starting score and final score.
3. Work from top to bottom. **Check off a task only after performing the required inspection or verifying the outcome**; a task does not necessarily require changing the system.
4. Mark tasks **N/A** when the exercise does not call for that service or feature. Record why in the notes area.
5. Always preserve forensic questions and README-required users, roles and services before remediation.
6. Use the original detailed guide when a task needs specific GUI instructions, commands, expected outputs, or rollback.

## Track completion on GitHub too

Each PDF has a matching Markdown file with **exactly the same task IDs and order**. Open its matching Markdown tracker and click **Edit this file** (pencil icon), replace `- [ ]` with `- [x]` for completed tasks, and **Commit changes**. A checkbox shown on a GitHub rendered Markdown page isn't automatically saved when clicked.

For team collaboration, each member can edit an assigned section on a feature branch/PR; avoid two people editing the same tracker simultaneously without coordination. If you prefer preserving an untouched checklist for each round, copy the Markdown tracker to a dated filename before marking it complete.
